Accounts

Connect GitHub, GitLab and your own server.

GitHub token permissions

For a fine-grained token, select the repositories you need and grant Contents: read and Pull requests: read. Organization approval or SSO authorization may also be required. GitHub may require additional permission to sync viewed-file marks; the sidebar reports failures.

With a classic token, private repositories need the repo scope. Public browsing works without a token, subject to GitHub's API limits.

GitLab token permissions

Use a personal access token with read_api to read private projects, merge requests, discussions and review-state filters. Your account must have access to the project.

Viewed-file marks are local to this browser. Public browsing works without a token, subject to GitLab's API limits. Review-state filters require a token and compatible server endpoints.

Keyboard shortcuts

Your data

Bookmarks and preferences are local to this browser profile. There is no account with us, subscription, analytics or backend.

Repository data goes directly between the extension and the selected GitHub or GitLab server. Tokens are kept out of page scripts and content-script storage access.
