Navigation

Choose when the tree appears and how you open it.

Use Ctrl, Cmd, Alt, Shift or Mod (Ctrl or Cmd), for example Mod+Shift+S. Separate alternatives with commas. Leave a field empty to disable it. Shortcuts are ignored while typing; browser-reserved shortcuts may take priority. Arrow keys and Enter navigate the tree.

Browser Sync

Optionally carry your preferences and bookmarks between devices.

Off by default. Uses this extension's browser Sync storage with your browser account, when browser sync is enabled. Devices need the same browser sync service and extension ID; other browsers may use a separate service.

Only appearance and navigation preferences, bookmark URLs, titles, repository names and creation dates are synced. Account tokens, connected accounts, server permissions, repository caches, Viewed marks and window pin states stay local. Bookmark URLs and titles can reveal private repository names.

When enabling on a device, existing synced preferences replace its saved preferences. Bookmarks are merged by URL, keeping this device's version for duplicates. Later changes use the latest synced snapshot. Refresh already open repository tabs to apply synced preferences.

Browser Sync has an 8 KiB snapshot limit and browser write quotas. Local bookmarks remain unlimited. If Sync fails, your local changes are kept and the error appears below. Disabling applies only to this device: local data and the shared copy used by other enabled devices are kept.

Accounts

Connect GitHub, GitLab and your own server.

Checking sign-in availability…

Enter on GitHub's device sign-in page.

GitHub token permissions

For a fine-grained token, select the repositories you need and grant Contents: read and Pull requests: read. Organization approval or SSO authorization may also be required. GitHub may require additional permission to sync viewed-file marks; the sidebar reports failures.

With a classic token, private repositories need the repo scope. Public browsing works without a token, subject to GitHub's API limits.

GitLab token permissions

Use a personal access token with read_api to read private projects, merge requests, discussions and review-state filters. Your account must have access to the project.

Viewed-file marks are local to this browser. Public browsing works without a token, subject to GitLab's API limits. Review-state filters require a token and compatible server endpoints.

Sidebar pinning

The pin button applies to every repository tab in the current window. Other windows keep their own pin state. New windows use the Appearance default.

Your data

Bookmarks and preferences stay local unless you enable Browser Sync above. The bounded repository-tree cache stays local. There is no account with us, subscription, analytics or backend.

Repository data goes directly between the extension and the selected GitHub or GitLab server. Tokens are kept out of page scripts and content-script storage access.
